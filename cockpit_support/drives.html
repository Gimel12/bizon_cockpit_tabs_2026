Performance & load test

OS / system drives cannot be tested. Selected data drives run concurrently. Read tests do not write to the drive. Write tests use a new temporary file on a mounted data volume and delete it afterwards. Temperatures and SMART error counters are recorded before, about every 10 seconds during, and after testing. Testing can slow other workloads; larger files and longer runs produce more sustained load.
